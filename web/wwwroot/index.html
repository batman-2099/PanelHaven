      Server settings

      Back to library

      These are saved server settings, not browser preferences. Application, library, network, TLS, and secret changes take effect only after restart. Backup scheduling is applied when saved; check its actual status below.

      Running configuration and recovery paths

      Running values below do not change when you save a restart-required setting. Recovery files are private server files; if a network change locks you out, restore the prior settings file on the server and restart.

      Saved configuration
      Libraries

      Removing a root does not delete comicbooks or catalog entries. Access to those files may be lost after restart until the root is added again. Scan libraries after restarting to discover newly added files.

      Leave blank to disable an area. Use separate, non-overlapping folders outside regular library roots. Archived comicbooks appear only with the Archived filter; Unsorted is a separate intake for comicbooks awaiting organization. Save, restart, then scan to discover files. Changing paths never moves files automatically; use Move / rename or Organize selected to review and confirm moves between areas.

      Comic Vine

      Leave a secret blank to keep it, enter a replacement to set it, or explicitly select Clear to remove it. Existing secrets are never displayed. Secret changes require restart.

      Network and TLS

      Trust only proxies you control. Listen URLs are server bindings, not necessarily browser addresses. Changing the protocol, host, port, or certificate can disconnect you after restart. Make sure the new address and HTTPS/proxy setup work before restarting.

      Scheduled backups

      Scheduled backups contain the database and data-protection keys only. They do not include comicbooks or this server settings file. Back up those separately. Scheduling requires Linux user systemd; a saved schedule is not proof that its timer is active.

      Service and startup

      Startup controls install or update this installation's owned Linux user service. They do not apply unsaved edits or immediately restart the application. Availability after a reboot also depends on your user service manager and login/lingering configuration.

      After restarting, reconnect manually at the saved address (or your reverse proxy address). This page will not redirect or retry a restart automatically. Wildcard bindings such as 0.0.0.0 or * must be replaced with the server's reachable hostname.

      Data location

      Data relocation is separate from configuration saving. It copies all application state, including the database and keys, on the next startup. Comic libraries stay where they are. The original data is preserved for recovery.

      Edit metadata

      Only checked fields and custom values are saved to the library database, never automatically to source comicbooks.

      Review exact changes

      Only actual changes are listed. Quoted values preserve whitespace; empty strings and removed values are shown explicitly. Applying changes updates only the library database.

            Move and undo history

            Organize selected books

            Only existing folders within configured libraries are allowed; no folders are created. Comicbooks keep their extension and contents, identity, metadata, list memberships, and private reading progress. Nothing moves until you preview and explicitly confirm.

            This batch runs sequentially, not all-or-nothing: it stops at the first execution failure and keeps earlier completed moves. No overwriting, path swaps, or cycles. Stop other programs from editing these files. Nothing is retried automatically.

            Destination templates

            Destination folders are always Publisher / Series, from saved metadata, and must already exist. Missing values use Unknown Publisher or Unknown Series. Filename tokens: {Series}, {Year}, {Number}, {Title}, {Publisher}, {Volume}, {FileName}. {FileName} keeps the original filename; its extension is appended unchanged. Explicit tokens reject missing metadata and unsafe values.

            Review every destination

            You can edit each complete filename (including its unchanged extension), then re-preview before confirming. Folders always use Publisher / Series. Displayed paths and hashes describe the last preview, not unpreviewed edits. Changing the root or filename template discards row edits.

            Per-book move history and recovery

            After a partial failure or lost connection, inspect each book's journal before doing anything else; do not assume an unconfirmed move failed. These history buttons work even when a book is unavailable. Undo and pending recovery require their own fresh preview and confirmation.

            Smart rules

            Use 1–20 rules, up to 20 nonempty groups and four levels. Not set finds missing metadata. Issue ranges use natural order; publication dates need a complete date. Rating 0 means unrated.

            Preview uses Library only, without search or basic filters. Preview before saving a smart list.

            Private list folders

            Organize private lists in nested folders. Deleting a folder unfiles only its direct lists and moves its immediate child folders to the top level, keeping their contents. No lists, books, or private reading data are deleted.

            Relocate application data

            The server validates the destination before queuing a move for the next startup. Its parent must already exist, but the destination itself must not exist. Use a separate absolute path outside library roots, application files, settings, and the current data directory; symlinks and overwriting existing contents are not allowed. Allow enough free disk space for the complete copy. The source is preserved. A failed copy keeps the old data location active.
